About DailyTrack

DailyTrack is a daily activity tracker that helps people plan their day, complete tasks and see how much they achieve over time. Users add activities, mark them as completed and review progress through charts on the dashboard.

It is designed as a Cloud Computing mini project. The frontend keeps all data access in two small service layers, so the browser storage used today can be swapped for a cloud database and cloud authentication without redesigning the interface.
